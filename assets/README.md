# `/assets`

Expo top-level assets referenced from `app.config.ts`. Replace placeholders
before publishing.

Required:
- `icon.png` — 1024×1024 app icon
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground
- `splash.png` — 1242×2436 splash image

Until generated, Expo will use built-in defaults at dev-time. Phase 6 wires
the final assets.
